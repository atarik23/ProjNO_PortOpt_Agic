# Mean-Variance Portfolio Optimizer

Course project for **Numerical Optimization**.

This project implements a long-only mean-variance portfolio optimizer using an active-set quadratic-programming algorithm. The graphical interface and dense and sparse linear-system backends use the professor-provided natID framework.

## Repository structure

- [`Implementation/`](Implementation/) — complete C++ implementation, natID resources, tests, and detailed build instructions

## Main features

- CSV import of periodic asset returns
- sample mean and covariance estimation
- active-set quadratic-programming solver
- global minimum-variance portfolio
- target-return optimization
- efficient-frontier construction
- natID dense and sparse matrix backends
- numerical backend comparison
- portfolio visualizations
- CSV export
- automated numerical tests
