# Report screenshots

The LaTeX report compiles without screenshots and displays labeled placeholders.
Before final submission, place the following PNG files in this directory and rebuild the report:

- `efficient_frontier.png` — the Efficient Frontier tab after constructing 25 frontier points and optimizing the 1% target-return portfolio;
- `portfolio_weights.png` — the Portfolio Weights tab for the same frontier;
- `backend_comparison.png` — the Optimization tab showing a successful dense-versus-sparse comparison.

Recommended procedure:

1. Use the bundled synthetic sample.
2. Select 25 efficient-frontier points and build the frontier.
3. Optimize a target return of `0.01`.
4. Capture only the application window at its default size.
5. Keep the exact filenames listed above; the LaTeX source will include them automatically.
